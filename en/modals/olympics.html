Olympics Coverage - Globo

Technical implementation of the Disguise system for 3D virtual environments in the Paris Olympics broadcast.

Disguise Ecosystem Real-time Graphics Broadcast

Project Challenge

The Olympics coverage required a robust and flexible solution to create dynamic virtual environments and real-time graphics during live broadcasts, maintaining perfect synchronization with multiple cameras and multiple servers.

Our Solution

We implemented a complete system based on the Disguise ecosystem to create interactive virtual environments in real-time. The solution included high-performance servers, integration with camera tracking systems, and a pipeline optimized for live broadcasts.

Results

The implementation was a success, allowing Globo to offer visually impressive and technically flawless Olympic coverage. The virtual environments and real-time graphics enriched the viewer's experience, providing visual context and information dynamically and engagingly.

The project received international recognition for technological innovation and visual quality, setting a new standard for large-scale sports coverage.
